## Sources essayées

- OpenGameArt.org : fonctionne sans compte, téléchargement direct, licence indiquée sur chaque page.
- incompetech.com : fonctionne sans compte, MP3 en lien direct, catalogue en JSON (https://incompetech.com/music/royalty-free/pieces.json).
- archive.org : fonctionne sans compte (métadonnées et fichiers via /download/), certains items renvoient "Access Denied". Sous Windows, `curl --ssl-no-revoke` peut être nécessaire.
