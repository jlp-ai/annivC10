Le signal dans le noir

Une perturbation venue d'un monde parallèle brouille la galaxie. Tous les messages de la flotte se sont éteints, un par un.

Dans la base secrète, plus aucune lumière. Les derniers codes sont cachés dans l'obscurité, écrits en lettres qui brillent seulement pour ceux qui savent les trouver.

Une équipe d'agents courageux vient d'atterrir. Sept messages lumineux les attendent. Il faudra les retrouver, puis les remettre dans l'ordre pour reconstituer le mot qui rallumera les étoiles.

Pas de panique. Avancez ensemble, restez groupés et laissez la lumière vous guider...

Mission dans le noir

Le bureau est plongé dans l'obscurité.

Trouvez les sept messages lumineux et remettez-les dans l'ordre.

Quand le mot est reconstitué, tapez-le à l'écran.

Espace = passer l'introduction, Entrée = ouvrir la saisie du mot (maître du jeu)
